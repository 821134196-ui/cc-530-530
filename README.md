# 企业通勤班车预约系统

按 **线路 / 站点 / 班次 / 车辆座位数** 开放预约；员工选择上车站与下车站，
区间满员进候补；司机车载端扫码核验，运营员查看实际乘坐与空座。

零依赖：仅使用 Python 3 标准库（`http.server` + `sqlite3`）。

## 一条命令启动

```bash
./run.sh                 # 重置演示数据并启动 http://127.0.0.1:8000
PORT=8080 ./run.sh       # 换端口
```

打开浏览器：

| 页面 | 地址 | 说明 |
| --- | --- | --- |
| 线路图 / 班次概览 | `/` | 站点顺序图、各班次区间占用与候补 |
| 员工预订 | `/book.html` | 站点顺序图选上/下车站，按区间显示余座 |
| 司机车载端 | `/driver.html` | **大字**下一站、待上车名单、扫码上下车 |
| 运营调度台 | `/ops.html` | 换车、绕行、出勤核销、乘坐记录、空座 |

右上角可切换演示身份（员工 e1–e14 / 司机 d1、d2 / 运营员 op1、op2）。

绕行样例（不启动服务的脚本演示）：

```bash
python3 -m shuttle.demo_detour     # 绕行改站 → 换车缩容 → 扫码幂等 → 爽约
```

## 核心模型：区间容量

一条班次的站点快照按 `seq` 排列，预约 `[board_seq, alight_seq)` 占用中间每一条边。

```
A ── B ── C ── D ── E
  e1   e1   e1            e1: A→D，占用 AB/BC/CD
       e2   e2            e2: B→D，占用 BC/CD
                 e3      e3: D→E，占用 DE
```

因此**整车没满，但某一区间满了，也会进候补**（种子班次 T2 即此场景：
中段 12/12 满，买全程的员工 13 进候补，只坐末段的员工 14 仍可订）。

- 候补递补按 `优先级（缩容降补）→ 入列时间 → id` 排序，逐人做**区间**检查；
  队首装不下时**跳过**，让更短区间的候补者先上。
- 所有写操作在全局写锁 + `BEGIN IMMEDIATE` 事务中完成“检查—插入—递补”，
  并发预约不会超卖（`TestConcurrentBooking`：20 线程抢 5 座）。

## 已覆盖的业务规则

- **临时换车**：缩容时把覆盖超载区间、最晚预订的 `booked` 降为高优先级候补，
  已上车（`boarded`）员工绝不被降补；扩容自动递补。
- **线路绕行**：仅作用于本班次站点快照（不影响模板与其他班次）；
  受影响预约自动改到最近可服务站点并标记“待确认”；无有效乘车间区则取消并通知。
- **员工改站**：按新区间重新校验容量，装不下转候补，按原预订时间排队。
- **迟到未上车**：关门离站时未扫码的 `booked` 判 `no_show`，
  错过上车站的候补自动取消，随后对后续区间重新递补。
- **候补递补**：区间感知，取消/下车/扩容/恢复站点都会触发。
- **重复扫码**：`scans` 上 `(trip_id, reservation_id, kind)` 唯一，
  重复扫直接返回首次核验结果（幂等），不翻转状态、不重复计数。
- **权限**：司机不能核销出勤（只能运营员登记）；运营员只能操作
  `operator_routes` 中被授权的线路（op1 管 R1，op2 管 R2）。

## 模拟适配器

- `shuttle/adapters.py` 的 `LocationAdapter`（定位）与 `NotificationAdapter`
  （通知）为模拟实现：位置随站点推进推导，通知写入 `notifications` 表
  （页面“我的通知”可查）。接入真实 GPS / 推送时只需替换这两个类。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

22 个用例覆盖：区间重叠容量、候补递补顺序（FIFO、跳过装不下者、降补优先）、
换车缩容与扩容、已上车不被降补、扫码上下车幂等、20 线程并发不超卖、
绕行改站/取消、爽约、改站候补、角色与线路权限。

## 代码结构

```
shuttle/
  db.py          SQLite 表结构、连接、写锁事务
  core.py        区间容量/候补递补/换车/绕行/改站/爽约/扫码/出勤/权限
  adapters.py    定位与通知模拟适配器
  seed.py        演示数据（T2 区间满员 + 候补，T3 绕行样例）
  server.py      零依赖 HTTP：JSON API + 静态页面
  demo_detour.py 命令行绕行/缩容/扫码样例
  static/        三个前端页面 + 线路图（白 / 深蓝 / 绿状态色）
tests/test_core.py
```
