# 企业通勤班车预约系统

按线路 / 站点 / 班次 / 车辆座位数开放预约，员工选择上车站与下车站；满员进入
区间候补，司机车载端扫码核验上车，运营员查看实际乘坐、空座并处理临时变动。

**纯 Python 标准库 + SQLite，零依赖。** 一条命令启动，内置绕行样例。

## 启动

```bash
python3 -m shuttle                 # 默认 http://127.0.0.1:8000，自动建库播种
python3 -m shuttle --port 9000 --reset
```

启动后访问 http://127.0.0.1:8000 ，首页可切换演示身份：

## 演示脚本（启动即有数据）

1. **绕行样例** — 班次 #1 07:40 滨江线：江景公寓**飞站**（在该站上车的
   员工自动转候补并收到推送），滨江花园后**新增临停“桥东岸”**；下车站被飞
   的乘客实际坐到下一站，座位占用自动延伸，不会把其座位误当空座超卖。
2. **区间满载 + 候补** — 班次 #2 08:00（8 座）：每条边满载，员工 19/20
   候补。取消任一确认票，观察按**区间 FIFO** 递补（内层区间的候补可能
   先于/晚于全程候补，取决于哪个区间先空出）。
3. **换车缩容** — 班次 #3 08:10：20 座 10 人，在运营台换成 8 座中巴，
   覆盖超员区间且最晚预约者自动降级候补并重排，所有边保证不超卖。

## 核心设计

### 区间容量（不只看整车人数）

线路 s0…sn-1 定义 n-1 条**边**。`[上车站, 下车站)` 的预约占用其覆盖的每条
边各 1 座。可订判定 = 覆盖的每条边 confirmed 占用 `< 车辆座位数`。
因此“前半段满、后半段空”时后半段仍可正常售卖；车上人数可以多于座位数，
但**任一时刻任意边的占用都不超过座位数**。

占用为实时聚合（不存冗余计数），飞站/临停时按“完整顺序 + 飞站标记”统一
计算，下车站被飞的乘客占用自动延伸到下一个有效站。

### 候补递补（区间感知 FIFO）

- 候补带 `queue_seq`，取消 / 改站 / 换车 / 飞站 / 驶离站点后自动重算。
- 从队首扫描：某候补的区间仍满则**跳过**（不阻塞区间不重叠的后到者），
  区间有空即递补并推送通知；循环扫描直到无新增。
- 车辆驶离某站后，上车站早于当前位置的候补**不再递补**（已错过站点）；
  该站未扫码的确认乘客标记 `noshow`（迟到未上车）并释放座位。

### 并发防超卖

所有写操作在 `BEGIN IMMEDIATE` 事务内完成“容量校验 + 写入”，SQLite 单写者
从源头串行化，20 线程抢 5 座的测试结果严格为 5 confirmed / 15 waitlisted，
无任何错误或超卖。

### 换车缩容

换小车后若某条边超载：选中覆盖超员边且 `created_seq` 最晚的确认者降级到
候补队尾并通知，重复直到全部边不超载，再执行统一区间 FIFO 递补，终态稳定。

### 扫码核验（幂等）

`boarded_at` 仅首次扫码写入，重复扫码只累加 `scan_count` 并返回“已上车”，
不产生重复乘坐记录。候补者在车端扫码时先跑完整 FIFO 递补，防止越队上车；
另拦截非本班次码、已取消码、非本车司机。

### 权限

- 司机可自助签到，**不能核销自己的出勤**；核销只能由授权线路运营员完成。
- 运营员换车 / 飞站 / 临停 / 核销 / 标记 no-show 全部在服务层校验
  `operator_routes` 授权（越权抛 `AuthzError`），UI 仅做提示。
- 关键动作写 `audit_log`。

### 模拟适配器

`shuttle/adapters.py`：`MockLocator`（车辆位置 / 下一站）、`MockNotifier`
（候补成功、降级、绕行、迟到等通知，页面“通知”卡片可查）。接真实 GPS /
推送时替换这两个类即可。

## 测试

```bash

```

28 个用例覆盖：区间重叠容量、区间感知递补顺序、改站腾座/退回队尾、
换车缩容/扩容、飞站（上车转候补 / 下客占用延伸）、临停班次隔离、
扫码幂等、迟到 no-show、20 线程并发不超卖、运营授权与核销限制、Web 全链路。

## 目录

```
shuttle/
  db.py        SQLite schema、连接、BEGIN IMMEDIATE 事务
  service.py   领域服务：区间占用、预约/候补/递补、换车、绕行、核验、no-show
  adapters.py  MockLocator / MockNotifier
  seed.py      演示数据（满员候补、缩容、绕行样例）
  app.py       stdlib http.server Web：预订页 / 司机端 / 运营台
  __main__.py  启动入口
tests/         领域 + Web 测试
```
